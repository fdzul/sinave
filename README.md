
# sinave

<!-- badges: start -->
<!-- badges: end -->

The goal of sinave is to reads the eleven datasets hosted in the vector-borne diseases module of the national epidemiological surveillance system of the federal health secretariat of Mexico

## Installation

You can install the development version of sinave from [GitHub](https://github.com/) with:

``` r
# install.packages("pak")
pak::pak("fdzul/sinave")
```

## Example

This is a basic example which shows you how to solve a common problem:

``` r
library(sinave)
## basic example code
```
